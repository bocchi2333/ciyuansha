# 次元杀 GameCore V2 规则基线

本文描述 `2.0.0` 规则内核的稳定边界。规则实现以次元杀原创内容为主体，标准与军争机制对照无名杀提交
`444c7278a6b4b4754eaad4299f77ab31ba8d1655`；源码学习关系见
[`noname-source-ledger.md`](noname-source-ledger.md)。

## 一局游戏如何推进

每个正常回合依次经历准备、判定、摸牌、出牌、弃牌、结束六个阶段，回合开始和回合结束是独立边界事件。
阶段事件都经过 `Before → Begin → Resolve → End → After`，可被跳过、替换或插入额外阶段。规则需要玩家输入时，
结算栈完全暂停，只接受当前 `ChoiceRequest` 对应且版本一致的 `ChoiceResult`。

稳定触发顺序为：特殊前置、优先级降序、从当前行动座位开始的座次顺序、技能 ID 字典序、特殊后置。
规则事件、随机结果、接受的选择和状态哈希都写入规则日志；所有随机数只来自比赛种子。

## 卡牌和公共规则

- 标准与军争牌堆共 161 张，花色、点数、类别和效果由 `Data/Packs` 声明。
- 杀、闪、桃、酒，以及普通、火焰、雷电伤害均在纯内核结算；酒的强化只保留到本回合结束。
- 决斗由双方轮流提交杀，直到一方拒绝或不能响应；南蛮、万箭和多目标锦囊按座次逐目标结算。
- 非延时锦囊支持逐目标无懈链；无懈也能被无懈，最终按链的奇偶性决定目标效果。
- 乐不思蜀、兵粮寸断、闪电进入判定区，在判定阶段处理。判定牌进入处理区后再进入弃牌堆；闪电未命中会传递。
- 濒死从当前座位开始按座次求桃，濒死者可用酒自救；所有救援结束后仍不大于 0 才死亡。
- 火焰和雷电伤害会沿横置角色传播。距离、攻击范围、进攻/防御坐骑和手牌上限由权威状态计算。
- 装备按装备栏替换；朱雀羽扇可把普通杀转换为火杀。区域牌选择提交稳定牌实例 ID，不由客户端指定结果。

## 模式

| 模式 ID | 人数 | 身份与胜负 |
| --- | ---: | --- |
| `duel` | 2 | 无隐藏身份，最后存活者获胜。 |
| `identity` | 4 | 主公公开；忠臣、反贼、内奸隐藏。主忠、反贼、内奸胜负和击杀奖惩由模式处理。 |
| `team_2v2` | 4 | A/B 队交错入座，消灭对方两席获胜。 |
| `boss_pve` | 2–4 | 一名机器人 Boss 对一至三名英雄；生命阈值触发二阶段和技能组变化。 |

身份模式的隐藏身份和推断信息不会进入无权查看者的 `GameView`。其他玩家、观战者和 AI 都拿不到私有手牌或私有候选项。

## 12 名原创武将

七名原有武将保留并迁移到 Skill V2。新增五名分别验证转换、判定控制、元素连环、队友支援和标记/限定爆发：

- 洛星野：`blade_conversion`，转换基本牌用法。
- 苏镜澜：`mirror_judgement`、`judgement_draw`，控制判定并从判定事件获益。
- 雷曦：`elemental_resonance`，强化属性与连环协同。
- 沈月白：`ally_supply`、`pain_draw`，支援队友并在受伤后补充资源。
- 寂焚心：`limit_break`、`first_damage_boost`，使用标记发动限定爆发；同时提供 Boss 模板。

全部技能声明都只能引用白名单 C# 效果 ID，不加载任意脚本或动态程序集。

## 本地规则差异

本版本有意保持以下窄化边界：

- 只支持本项目列出的四种模式和固定人数，不包含国战、斗地主、5–8 人身份或主机迁移。
- 内容包是带哈希的 JSON 声明加内置 C# 效果，不兼容无名杀扩展脚本格式。
- 借刀杀人和火攻使用当前项目的稳定简化向量；前者不开放任意二级目标脚本，后者不公开目标手牌内容。
- 装备采用本项目已经公开的装备栏、距离和触发集合，不导入无名杀素材、角色台词或扩展包专属规则。

这些差异是规则边界，不是客户端自行决定的特例；录像和联机都由同一内核重放。
