## 快速索引

- 关键词：回合阶段、出牌阶段、摸牌阶段、弃牌阶段、判定、响应、濒死、死亡、伤害、属性伤害、距离、攻击范围、手牌上限、装备区、判定区、处理区、无懈可击。
- 牌类：基本牌、锦囊牌、延时锦囊、装备牌、武器、防具、坐骑、宝物。
- 重要实现映射：`GameManager` 管回合与规则窗口，`ActionManager` 管结算队列，`DamageAction` 管伤害，`TrickUseAction` 管锦囊，`PlayerCharacter` 管角色状态、手牌、装备、判定区。

## 规则优先级

- 当技能、牌面效果、通用流程冲突时，通常按“技能说明优先于牌说明，牌说明优先于通用规则”的方向处理。
- 结算必须关注触发时机、响应窗口、目标是否合法、效果是否被抵消或无效。
- 多名角色或多个目标需要依次处理时，应按座次或指定顺序逐个结算，避免一次性批处理导致响应窗口错乱。

## 牌与区域

- 游戏牌有花色与点数，判定牌、八卦阵、闪电、乐不思蜀、兵粮寸断等都依赖花色/点数。
- 游戏牌分为基本牌、锦囊牌、装备牌。
- 锦囊牌分为非延时锦囊和延时锦囊。
- 装备牌分为武器、防具、坐骑、宝物。
- 角色区域通常包括手牌区、装备区、判定区。
- 公共区域包括牌堆、弃牌堆、处理区。
- 装备区同类槽位通常只能放一张牌：武器、防具、-1坐骑、+1坐骑、宝物。
- 替换装备时，新装备进入对应槽位，旧装备进入弃牌堆。
- 当某装备正在提供距离、攻击范围或技能效果时，不应同时把该装备作为弃置/转化等成本操作。

## 回合流程

- 回合开始：触发回合开始技能，结算判定区延时锦囊。
- 判定相关：翻出牌堆顶牌作为判定牌，根据花色/点数判断结果，判定牌进入弃牌堆。
- 摸牌阶段：通常摸 2 张；装备/技能可修改摸牌数量。
- 出牌阶段：玩家主动使用牌，通常系统暂停自动流转等待 UI 输入。
- 弃牌阶段：若手牌数大于手牌上限，需要弃到上限。
- 手结束后进入下一名存活角色回合。

## 基本牌

### 杀

- 使用时机：出牌阶段。
- 通常限制：每个出牌阶段限使用 1 张。
- 目标：攻击范围内一名其他角色。
- 效果：对目标造成 1 点伤害。
- 类型：普通杀、火杀、雷杀。
- 火杀造成火焰伤害，雷杀造成雷电伤害。
- 响应事件中要求“杀”时，普通杀、火杀、雷杀通常都可作为杀响应，除非效果另有限制。
- 代码建议：`CardRules.IsSlash()` 统一判断。

### 闪

- 使用时机：以自己为目标的杀生效前，或某些锦囊/技能要求打出闪。
- 效果：抵消对应杀，或满足响应要求。
- 代码建议：伤害型闪避与“万箭齐发要求打出闪”要区分上下文。

### 桃

- 出牌阶段可使用，通常回复 1 点体力。
- 濒死结算中可用来救援处于濒死状态的角色。
- 代码建议：濒死响应窗口应按顺序询问可救援角色，直到脱离濒死或死亡。

### 酒

- 出牌阶段每回合限一次。
- 非濒死时：本回合下一张杀伤害基数 +1。
- 自己濒死时：作为自救，回复 1 点体力。
- 代码建议：酒杀加伤不能跨回合保留；回合结束或弃牌阶段清空未使用加伤。

## 锦囊牌

### 过河拆桥

- 出牌阶段使用。
- 目标：一名区域里有牌的其他角色。
- 效果：弃置目标区域里一张牌。
- 代码建议：先做“优先手牌，再装备”的简化选择；后续 UI 应允许选择区域与具体牌。

### 顺手牵羊

- 出牌阶段使用。
- 目标：距离为 1 且区域里有牌的其他角色。
- 效果：获得目标区域里一张牌。
- 代码建议：距离检查必须包含进攻马/防御马/技能修正。

### 决斗

- 出牌阶段使用。
- 目标：一名其他角色。
- 效果：目标开始，双方轮流打出杀；先不出杀的一方受到对方造成的 1 点伤害。
- GameCore V2：双方轮流打出杀，直到一方取消或不能响应并受到伤害。

### 无中生有

- 出牌阶段使用。
- 目标：自己。
- 效果：摸 2 张牌。

### 无懈可击

- 使用时机：一张锦囊牌对一个目标生效前。
- 效果：抵消该锦囊对该目标的效果。
- 重要机制：无懈可击本身也可以被无懈可击响应，形成链式抵消。
- 代码建议：可用奇偶逻辑处理无懈链，最终判断原锦囊是否生效。

### 南蛮入侵

- 出牌阶段使用。
- 目标：所有其他角色。
- 效果：每名目标依次需打出杀，否则受到 1 点伤害。
- 代码建议：必须逐个打开响应窗口，不能一次性群体扣血。

### 万箭齐发

- 出牌阶段使用。
- 目标：所有其他角色。
- 效果：每名目标依次需打出闪，否则受到 1 点伤害。
- 代码建议：这里要求“打出闪”，不是杀伤害流程中的普通闪避上下文。

### 桃园结义

- 出牌阶段使用。
- 目标：所有角色。
- 效果：每名目标回复 1 点体力。
- 代码建议：已满血角色通常不会实际回复。

### 五谷丰登

- 出牌阶段使用。
- 目标：所有角色。
- 效果：亮出等同目标数的牌，目标按顺序各获得一张。
- 代码建议：当前可先按座次自动拿第一张；后续应做公共牌池选择 UI。

## 延时锦囊

### 乐不思蜀

- 放入目标判定区。
- 目标回合开始时判定。
- 判定规则：红桃通过，不跳过出牌阶段；否则跳过出牌阶段。

### 兵粮寸断

- 放入目标判定区。
- 目标回合开始时判定。
- 判定规则：梅花通过，不跳过摸牌阶段；否则跳过摸牌阶段。
- 使用目标通常有距离限制，应按规则检查距离。

### 闪电

- 放入判定区，目标回合开始时判定。
- 判定规则：黑桃 2-9 命中。
- 命中：受到 3 点雷电伤害。
- 未命中：传给下一名角色的判定区；若无法传递则进入弃牌堆。

## 装备牌

### 武器通用

- 武器提供攻击范围和/或技能。
- 使用杀检查攻击范围。
- 部分武器会修改杀次数限制、目标、防具影响、伤害结算。

### 诸葛连弩

- 攻击范围：1。
- 效果：使用杀无次数限制。
- 代码映射：`EquipmentEffectType.Crossbow`。

### 青釭剑

- 效果：使用杀指定目标后，无视其防具。
- 代码映射：`EquipmentEffectType.QinggangSword`。

### 八卦阵

- 防具。
- 当需要使用/打出闪时，可进行判定；红色视为提供闪。
- 代码映射：`EquipmentEffectType.EightDiagram`。

### 仁王盾

- 防具。
- 通常能抵挡黑色普通杀，具体以版本规则为准。
- 当前项目简化：阻挡普通杀，若攻击者无视防具则不阻挡。
- 代码映射：`EquipmentEffectType.RenwangShield`。

### 藤甲

- 防具。
- 通常和南蛮/万箭/普通杀/火焰伤害存在特殊交互。
- 当前项目简化：物理伤害减 1，火焰伤害 +1。
- 代码映射：`EquipmentEffectType.VineArmor`。

### 坐骑

- -1 坐骑：自己计算到别人距离时距离减少。
- +1 坐骑：别人计算到自己距离时距离增加。
- 代码映射：`AttackDistanceModifier`、`DefenseDistanceModifier`。

### 宝物

- 宝物为独立装备槽。
- 当前项目中玉玺简化为摸牌阶段额外摸 1 张。
- 代码映射：`EquipmentEffectType.ImperialSeal`。

## 判定规则摘要

- 判定通常翻牌堆顶牌。
- 判定牌根据花色、颜色、点数决定成功/失败。
- 判定牌结算后进入弃牌堆。
- 当前项目应使用 `JudgeCard(target, reason, predicate)` 统一实现。
- 红色：红桃、方块。
- 黑色：黑桃、梅花。

## 伤害与濒死

- 伤害有来源、目标、数值、属性。
- 属性伤害包括火焰、雷电。
- 伤害结算后若角色体力降至 0 或以下，进入濒死。
- 濒死流程中按顺序询问可使用桃/酒的角色，直到目标体力回到 1 以上或死亡。
- 死亡后处理弃牌、移出存活角色、检查胜负条件。

## 距离与攻击范围

- 使用杀要求目标在攻击范围内。
- 距离会被坐骑、装备、技能改变。
- 攻击范围通常由武器提供。
- 顺手牵羊、兵粮寸断等牌也可能需要距离条件。

## 当前项目已覆盖

- 回合阶段：回合开始、摸牌、出牌、弃牌。
- 动作队列与响应窗口。
- 基本牌：杀、火杀、雷杀、闪、桃、酒。
- 锦囊：过河拆桥、顺手牵羊、决斗、无中生有、无懈可击、南蛮入侵、万箭齐发、桃园结义、五谷丰登。
- 延时锦囊：乐不思蜀、兵粮寸断、闪电。
- 装备槽：武器、防具、-1坐骑、+1坐骑、宝物。
- 装备效果：诸葛连弩、青釭剑、八卦阵、藤甲、仁王盾、玉玺雏形。
- 判定牌：已支持花色、点数、判定后弃置。
- 弃牌阶段：已改为手动弃牌输入。

## V2 后续扩展边界

- 借刀杀人和火攻当前采用公开规则文档中的稳定简化向量。
- 旧 Godot HUD 的专用输入桥最终会全部改为直接渲染 `ChoiceRequest`。
- 其余装备扩展只能通过权威事件和 Skill V2 加入，不在客户端命令中增加特例。
