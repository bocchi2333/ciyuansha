# 《次元杀》商业化水墨暗武侠 UI 规范 v1

> 状态：2026-07-28 第一轮一体化重构已落地。本文是后续 UI、动效和资产制作的统一约束。

## 视觉目标

- 核心气质：暗色水墨武侠牌桌、旧纸牌、青铜金边、朱红决策、雾中庭院。
- 第一眼必须先看懂回合与阶段，再看懂可操作牌和目标，最后才是氛围装饰。
- 所有界面共用一套字体、颜色、描边、面板层级和动效节奏，不再为单个窗口临时造样式。
- 不使用霓虹赛博、纯黑扁平面板、通用手游渐变按钮或高频粒子噪声。

## 设计令牌

- 墨黑背景：`#090B0C`，用于最底层与遮罩。
- 深墨面板：`#15130F`，透明度按层级保持在 88%-96%。
- 旧纸主色：`#D7C49C`，用于正文、牌面和高可读文字。
- 暗金强调：`#C09658`，用于边框、标题、主操作和当前阶段。
- 朱红危险：`#B53C2F`，用于伤害、放弃响应和不可逆操作。
- 青玉可用：`#4D8A67`，用于可操作、治疗和成功状态。
- 火焰：`#D66A32`；雷电：`#8065C7`。

## 字体

- 标题与阶段：思源宋体 `SourceHanSerifCN-Regular.otf`。
- 正文与按钮：霞鹜文楷 `LXGWWenKai-Medium.ttf`。
- 最小正文建议 15 px，主要按钮不低于 16 px；关键阶段标题 26-34 px。
- 英文武将名允许保留，但技能名、阶段、操作和日志必须优先显示中文。

## 局内层级

1. 背景层：原创夜庭院与墨色氛围，不承载交互。
2. 战场层：玩家武将卡围绕中央舞台，中央只显示阶段、提示、牌堆和弃牌。
3. 常驻 HUD：左上状态、右上目标、右侧战局记录、底部手牌。
4. 决策层：响应、选牌、无懈和救援必须使用全屏压暗与中央高优先级舞台。
5. 结算层：伤害、治疗、闪避和无懈使用 0.3-0.6 秒轻量反馈，不阻塞规则队列。

## 交互状态

- 默认：暗金细边，纸色正文。
- 悬停：轻微上浮与亮边，不改变布局占位。
- 选中：上浮、金边和局部扫光同时出现。
- 可响应：青玉或暗金呼吸提示，禁止只依赖颜色传达。
- 不可用：降低透明度并保留原因提示，不能简单隐藏。
- 危险操作：朱红按钮，文案明确说明后果。

## 动效节奏

- 大厅/局内切换：约 0.32 秒墨色揭幕。
- 阶段变化：约 0.24-0.34 秒中央舞台呼吸，不遮挡玩家操作。
- 响应窗口：约 0.18 秒弹入，背景同步压暗。
- 卡牌悬停：约 0.12-0.18 秒上浮；禁止持续抖动。
- 伤害与属性结算：朱红、火橙、雷紫各自独立，反馈完成后自动清理。

## 分辨率与安全区

- 主设计比例为 16:9；最低人工验收分辨率为 1366x768。
- 手牌与主操作按钮必须完整位于底部 2% 以上的安全区内。
- 右侧日志和目标面板不得覆盖中央响应窗口。
- 1920x1080 允许扩大留白，不应无上限放大字体或卡牌。

## 资产准入

- 允许：自制资源、明确授权的开源资源、已保留许可文件的 OFL 字体、项目原创生成背景。
- 禁止：反编译商业游戏资源、只有缓存文件而无来源许可的纹理、无法追溯作者与授权的网络图片。
- `E:\slay the spire` 中经项目负责人确认授权、逐项筛选并登记的资源允许进入构建；未登记内容仍不得自动导入。
- 每个正式资产必须登记来源、许可、用途、哈希和目标路径，详见 `Docs/asset-license-ledger.md`。

## 当前落地范围

- 大厅与选将：山亭背景、三栏大厅、武将预览、房间玩家与统一操作栏。
- 局内：庭院背景、中央阶段舞台、玩家武将卡、手牌、目标、日志、状态与响应窗口。
- 卡牌：旧纸牌面、类别色带、花色点数、扇形错落、选中与禁用状态。
- 反馈：阶段呼吸、窗口弹入、出牌牌影、物理/火焰/雷电序列帧、治疗/响应/阵亡反馈与分层音效。

## 表现架构

- `NetworkPresentationEvent` 是跨端演出数据，不参与规则结算。
- `BattleFxDirector` 统一管理目标定位、序列帧、着色器、3/5/7 档音效并发、随机音高、视觉预算和低动态降级。
- 全局 `PresentationSettingsPanel` 已覆盖大厅与局内，设置保存在 `user://ciyuansha_settings.cfg`；详细约束见 `Docs/presentation-settings.md`。
- `Scenes/Test/BattleFxShowcase.tscn` 是独立校准场景；详细映射见 `Docs/battle-fx-system.md`。
- 所有正式表现资源的来源、授权确认和 SHA-256 见 `Docs/asset-license-ledger.md`。
- `SystemDialogPanel` 作为大厅与局内共用的全局系统层，统一承载安全退出、连接失败、房主断线、错误详情和重连操作。
- 系统弹窗沿用暗金外框、朱红警示线、内嵌详情框和主次操作区；关闭窗口请求不再直接退出游戏。
- `BattleLogTextLocalizer` 与 `NetworkTextLocalizer` 只处理展示文字，权威规则日志与联机序列化字段保持稳定。
